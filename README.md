# SCANOVA — Site vitrine final mobile-first

Design mobile-first inspiré Apple : clair, premium, intuitif.

## Lancer en local
```bash
npm install
npm run dev
```

## Déployer sur Vercel
1. Crée un dépôt GitHub.
2. Envoie tous les fichiers du dossier.
3. Connecte le dépôt à Vercel.
4. Framework : Vite.
5. Build command : `npm run build`.
6. Output directory : `dist`.
